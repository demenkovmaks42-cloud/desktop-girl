# Desktop Girl 🖥️👧

Десктопное приложение на Electron.

## 📖 О проекте

Это простое десктопное приложение, созданное на базе фреймворка **Electron**. Оно использует веб-технологии (HTML, CSS, JavaScript) для создания пользовательского интерфейса и имеет доступ к системным функциям (например, к хукам клавиатуры и мыши).

## 🚀 Как запустить проект

Если вы скачали проект и хотите его запустить, выполните следующие шаги.

### 1. Требования
* Установленный [Node.js](https://nodejs.org) (рекомендуется LTS-версия, например, 18.x или 20.x).
* **Для Windows:** установленный инструмент сборки (Visual Studio Build Tools с компонентом "Разработка классических приложений на C++") — он необходим для компиляции нативных модулей (например, `uiohook-napi`).

### 2. Установка зависимостей
Откройте терминал в папке с проектом и выполните:
```bash
npm install

### 3. Запуск приложения
```bash
npm start
